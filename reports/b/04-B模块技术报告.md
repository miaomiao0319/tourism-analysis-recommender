# 成员 B 技术报告：景点统计与智能推荐

## 1. 设计与数据流程

A 将来源数据清洗为有 batch_id、地区、等级、类型、价格与证据引用的标准批次，上传 HDFS 并导入 MySQL。B 在同一批标准数据上执行 Hadoop MapReduce 城市、等级统计与 Spark SQL 多维分析，使用完整分组键对账，产出标准统计及运行元数据；A 复核后事务导入统计并按发布条件管理批次状态。在线端由 C 的 Flask 加载指定 ready 批次和 A 的只读候选迭代器，再调用 B 的纯函数推荐，结果及理由通过 API 返回页面。离线作业不会在网页请求时启动。

## 2. Hadoop MapReduce

使用 Hadoop Streaming：mapper 验证标准 CSV 字段、批次和等级状态，每条景点分别输出城市和等级两个 JSON 维度键及计数 1；shuffle 按键排序分组，reducer 顺序累加生成计数，随后转换成统一统计格式。城市未知保留空键组，等级未知与冲突各自保留。最终批次 YARN 作业 `application_1795620546449_0002` 成功，输出城市 337 组、等级 4 组，各维度各合计 8,431。输出键为标准维度，不以显示名称代替城市标识。

## 3. Spark SQL 多维统计

Spark 对 HDFS 标准 CSV 使用显式 schema，解析类型 JSON，再以 SQL group by 统计总体、省、城市、等级、城市×等级及展开后的类型；额外汇总城市、类型、等级及价格质量。可比较价格限定已批准政策、币种与免费/确定金额，生成总体、城市、等级价格汇总及直方图；无样本保留 `no_data`。类型可多标签，一个景点可计入多个类型。最终批次 Spark 结果 1,937 条，实际执行模式 `local[2]`，不是 YARN Spark 作业。

## 4. 双引擎对账

将两引擎同批 `attraction_count` 的完整城市或等级 dimensions 作为键，分别比较键集合与每组 count，并验证各维度总数。20261102_02 城市 337 组、等级 4 组全部一致，各为 8,431；最终批次 20261126_02 也同样通过。对账只覆盖两个共同计数维度，不能代替价格、类型、运行来源和发布条件的全部检查。两批现均为 ready，网站选择后者；两批不能混用。

## 5. AHP–TOPSIS–MMR

输入偏好先验证批次字典、地区、兴趣及预算；兴趣是硬筛选（至少一个类型命中），预算仅接受符合政策和证据的确定或免费价格，未知价格在有预算时排除。完整消费候选，不按最终展示数量预截断。

**AHP：**对互反判断矩阵 A，按行几何均值 `g_i=(∏_j a_ij)^(1/n)`，归一化 `w_i=g_i/Σg_i`；计算 `CI=(λmax-n)/(n-1)`、`CR=CI/RI`，要求 CR<0.10。指标顺序是兴趣、等级、价格：

| 模式 | 初始权重 |
|---|---|
| balanced | 1/3，1/3，1/3 |
| interest | 0.6，0.2，0.2 |
| economy | 0.2，0.2，0.6 |
| quality | 0.2，0.6，0.2 |

四矩阵本次 CR 均为 0。未提供的兴趣、预算指标先移除并重新归一；所有候选该指标值相同的列也会从 TOPSIS 移除并重新归一，因此有效权重可能与初始权重不同。兴趣值为命中偏好类型数/偏好类型数；已定级 CN_A 为等级数字/5，未知或冲突记 0；预算大于零时价格收益为 `1-票价/预算`，零预算的合格免费票为 1。

**TOPSIS：**对有效收益列向量归一化并乘有效权重，求每列正、负理想解，与它们的欧氏距离记为 `D+`、`D-`，贴近度 `C=D-/(D++D-)`。只有一个候选时得 1；所有特征无差异时得 0.5。分数是当前候选集合内的相对贴近度，不是满意率、游客评分或跨次可比的绝对质量。

**MMR：**先取最高 TOPSIS 分；后续最大化 `0.8 × C − 0.2 × max Jaccard(类型集合, 已选类型集合)`，处理分数相同时按既定名称和 ID 稳定排序。空类型集合按实现相似度记 0，缺少类型并不证明真实景点多样；返回值保留 TOPSIS 原始排名，便于解释重排。

## 6. 真实验证及分析结论

2026-11-26 对历史批次 20261102_02 使用真实 MySQL 和 Flask test client：四种模式均 HTTP 200，国家 CN 时 8,431 候选参与；70 元返回两条，0 元无匹配，MMR 第二条原 TOPSIS 第 4。该测试不能冒充最终批次逐模式验收。2026-11-27 最终批次 20261126_02 的六个真实接口通过，浏览器 0 元返回北京世界公园；此前同批直接函数验证 45 元匹配 3 条、70 元匹配 5 条。更多条件与字段理由见《真实推荐与接口验证》。

最终批次真实分析：①31 省级地区中山西 620、河南 515、四川 454，城市未知 277；可做省份排名与城市排名。②4A 4,811、5A 715、未知 2,898、冲突 7，可做等级结构图，明确未知并非低级。③自然 2,341、历史遗产 3,636、文化 1,532，类型是多标签，适合柱图而非假设互斥的饼图。④可比价格只有 7/8,431，不能推断全国票价。完整口径见《真实景点数据统计与分析》。
